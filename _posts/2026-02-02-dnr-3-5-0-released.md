A new minor version of dotNetRDF has been released.

This release addresses an issue in the SHACL processor and makes a number of internal changes to modernize the C# used in the code-base.

It is proposed that 3.5.x will be the final 3.x minor version. This release will receive priority bug fixes and dependency updates, but future feature development will focus on a 4.0 major release.

For more details on the changes in this release, please refer to the change log.

[Change Log](https://github.com/dotnetrdf/dotnetrdf/blob/master/ChangeLog.txt).

dotNetRDF 3.5.0 can be found [here on NuGet](https://www.nuget.org/packages/dotNetRDF/3.5.0) and also on [GitHub](https://github.com/dotnetrdf/dotnetrdf/releases/tag/v3.5.0).
