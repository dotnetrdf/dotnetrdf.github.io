A new bug-fix version of dotNetRDF has been released.

This release addresses a small memory leak due to unreleased event handlers when processing SPARQL queries.

For more details on the changes in this release, please refer to the change log.

[Change Log](https://github.com/dotnetrdf/dotnetrdf/blob/master/ChangeLog.txt).

dotNetRDF 3.5.1 can be found [here on NuGet](https://www.nuget.org/packages/dotNetRDF/3.5.1) and also on [GitHub](https://github.com/dotnetrdf/dotnetrdf/releases/tag/v3.5.1).
